PIDORAS COIN — автоматическая сборка APK для Windows

1. Распакуй архив в обычную папку.
2. Дважды нажми BUILD_APK.bat.
3. При первом запуске нужен интернет: скрипт сам скачает JDK 17, Android SDK и Gradle.
4. После успешной сборки рядом появится PidorasCoin.apk.
5. Перекинь APK на Android и установи. Возможно, Android попросит разрешить «Установку неизвестных приложений» для файлового менеджера/браузера.

Приложение:
- монетка 50/50;
- PIDORAS / INTE PIDORAS;
- анимация вращения;
- вибрация при выпадении;
- работает офлайн;
- не требует разрешений и интернета.
