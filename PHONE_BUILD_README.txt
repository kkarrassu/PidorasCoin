СБОРКА APK ТОЛЬКО С ТЕЛЕФОНА ЧЕРЕЗ GITHUB

1. Создай новый пустой репозиторий на GitHub.
2. Загрузи ВСЁ содержимое папки PidorasCoin в корень репозитория, включая папку .github.
3. После загрузки GitHub Actions автоматически начнёт сборку.
4. Открой вкладку Actions -> последний запуск "Build PidorasCoin APK".
5. Внизу страницы в Artifacts нажми "PidorasCoin-APK".
6. Скачается ZIP. Распакуй его — внутри PidorasCoin.apk.
7. Открой APK на Android и разреши установку из этого источника, если система попросит.

Если автоматический запуск не появился: Actions -> Build PidorasCoin APK -> Run workflow.
